# 🚢 이음수산 바다 낚싯배 (낚싯배 이음호)

목포 생선가게 **이상한 생선가게 이음수산**이 띄운 웹 낚시 메타버스입니다.
설치 없이 브라우저에서 바로 들어와, 목포 앞바다에 닻을 내린 낚싯배 '이음호'에 앉아 낚시를 합니다.

## 무엇을 하나요

1. **앉기** — 주황 화살표가 가리키는 빈 방석을 누릅니다. (5번 자리는 선장 자리)
2. **던지기** — 버튼(또는 스페이스바)을 꾹 눌러 힘을 모았다가 놓습니다. 멀리 던질수록 깊은 곳.
3. **기다리기** — 물멍. 톡톡 건드리는 가짜 입질은 참고, 다가오는 그림자를 지켜봅니다.
4. **챔질** — 찌가 '쏙' 잠기는 순간 누릅니다.
5. **끌어올리기** — 누르면 그물 바구니가 올라가고, 떼면 내려갑니다. 물고기를 바구니 안에 담아 두면 성공.

- **생선 도감 12종**: 이음수산이 실제로 파는 대표 생선 12종. 그림은 직접 그린 수채화이고, 깊이는 '생선12종 서식 수심' 포스터를 따릅니다.
- **밤바다에서 건진 것 8가지**: 밤 8시~새벽 5시에는 가끔 생선이 아닌 것이 올라옵니다.
- **하늘과 바다**는 들어온 사람의 실제 시각을 따라 낮·노을·밤으로 바뀝니다.
- 휴대폰에서는 **📱 가로 화면** 버튼으로 크게 할 수 있습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (three.js r128을 CDN에서 불러옴) |
| `logo.webp` | 이음수산 로고 (배 간판·선체) |
| `fish/*.webp` | 생선 12종 수채화 (배경을 투명하게 다듬은 것) |
| `.nojekyll` | 깃허브 페이지에서 파일을 그대로 내보내기 위한 빈 파일 |

기록(도감·최고 크기·기록장)은 각자 브라우저(localStorage)에만 저장됩니다.

## 깃허브 페이지로 열기

저장소 **Settings → Pages → Build and deployment**에서
Source를 *Deploy from a branch*, Branch를 `main` / `(root)`로 두고 저장하면
`https://hangunada-create.github.io/ieum-fishing-boat/` 주소로 열립니다.
